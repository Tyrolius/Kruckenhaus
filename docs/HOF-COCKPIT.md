# Hof-Cockpit – umgezogen

Der Plan für das Hof-Cockpit (Aufgaben, Fristen, Eingangsrechnungen,
Gasthaus-Abrechnung aus Bertha, Bargeld, Bankabgleich) ist am 22.10.2026 in
ein eigenes, **privates** Repository umgezogen: **Tyrolius/Jarvis**.

Jarvis ist der persönliche Assistent für Hof und Privates und läuft als eigener
Cloudflare Worker mit eigener D1-Datenbank. Die Website bleibt davon getrennt.

Was die Website später dafür beiträgt: eine Lese-Schnittstelle für
Ferienwohnungs-Anfragen, Anreisen und offene Hofladen-Posten, mit eigenem
Schlüssel nach dem Muster von `/api/extern/v1/` (Jarvis-Plan, Phase J3).
Bis dahin ist hier nichts zu tun.
